## 二、企业自身主要风险（动态二级章节）

一级标题固定保留。本节只为确实存在 Material Risk Evidence 的类别生成二级章节；
禁止为"凑完整"而输出"未发现……"的空章节。

- 仅当某类别存在实质风险证据时，才生成对应 `### 2.x` 小节，
  编号按实际输出顺序顺排（如只有财务与司法，则为 2.1 财务、2.2 司法）。
- 正常信号（财务稳定、招聘扩张、正面/中性舆情）不得在本节逐项展开；
  只有具备实质缓释意义时才写入"五、风险缓释因素与矛盾信号"，否则不写。
- 若 material_risk_count == 0（自身无显著风险），本节只保留一段简洁结论，
  例如："经工商、司法、舆情、财务及招聘等多源信息交叉核查，当前未发现需要单独列示的企业自身实质性风险。现有工商变更属于正常管理调整，财务及经营活动信号总体稳定。"
  然后直接进入第三章。

### 工商与经营风险（仅当存在时输出）

只写：行政处罚 / 经营异常 / 股权冻结 / 异常频繁的重要工商变更 /
其他真正影响经营稳定性的事件。
普通注册地址变更、法定代表人变更等无风险信号支持的工商变更，不得单独列为风险。

### 司法风险（仅当存在时输出）

只写：被执行 / 被告重大诉讼 / 限制消费 / 股权冻结 / 大额未决案件。
原告身份不得自动作为负面风险。

### 舆情风险（仅当存在时输出）

只写 negative 舆情、对经营信用合规有实际影响的舆情、尚未核实但值得关注的重要负面信号。
positive / neutral 原则上不逐条列出，仅作缓释/矛盾信号时引用。

### 财务风险与经营趋势（仅当存在时输出）

严禁直接展示完整三年财务数据表。必须提炼趋势：
营业收入明显下降 / 净利润持续下降或转负 / 经营现金流恶化 /
负债率明显上升 / 流动比率持续下降 / 应收账款异常增加 / 审计意见异常。
示例："2023—2025年营业收入持续下降，同时经营现金流由正转负，显示经营质量出现恶化趋势（Fxxx、Fxxx、Fxxx）。"
完整财务数据保留在企业详情页 / Evidence Drawer。

### 招聘与经营活动信号（仅当存在时输出）

招聘属弱信号，仅当 hiring_freeze / recruitment_reduction / 大规模岗位撤回 /
招聘活动明显收缩 / 招聘扩张与其他风险形成明显矛盾时写入。不要罗列全部岗位。

## 四、多源证据综合分析

不要按 B/J/P/F/H 逐个重新罗列。

综合回答不同来源的信息是否：
- 相互支持
- 相互矛盾
- 相互补充

示例：
"司法与经营事件显示关联企业风险较为集中，同时负面舆情进一步强化外部风险关注。但目标企业自身财务指标总体稳定，招聘活动仍保持扩张，因此当前证据更支持'关联风险值得关注'，而不足以判断目标企业已经出现严重经营危机。"

这一部分必须体现 Multi-Source Reasoning，而不是 Multi-Source Listing。

---

## 五、风险缓释因素与矛盾信号

必须呈现"不是所有信息都支持高风险"。

例如：
- 司法风险高，但收入仍增长
- 舆情负面，但经营现金流改善
- 存在行政处罚，但招聘仍扩张
- 关联企业风险高，但目标企业自身财务稳定

禁止为了报告"故事一致"而故意忽略与风险结论不一致的数据。

如果没有明显缓释因素：
写"暂未发现具有实质缓释作用的证据。"

## 七、证据限制与不确定性

必须明确区分：
- 事实
- 推断
- 尚未核实的信息

例如：
- 未核实舆情不能当成事实；
- 招聘变化只是经营活动信号；
- 关联企业风险不等于风险已经传导；
- 财务指标仅反映已提供期间；
- 现有关系网络可能无法覆盖所有实际控制关系。
