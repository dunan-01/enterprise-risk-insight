# 企业风险 Harness 实验总结报告

## 实验概述

本次实验对企业风险调查系统进行了全面测试，依次分析了5家企业（C001-C005），每个企业都独立完成了完整的风险调查流程。

## 实验流程

每个企业均执行以下完整流程：
1. 使用 risk_* 工具自主调查目标企业
2. 生成 Draft V1
3. 调用 coverage-auditor 检查调查完整性
4. 如果 COVERAGE_STATUS: INCOMPLETE，则继续调查遗漏企业和风险路径
5. Coverage 完整后调用 risk-verifier
6. 如果 VERDICT: REVISE，则根据审核意见修改报告并再次送审
7. 直到 PASS，或达到规定最大审核轮数
8. 最终报告显式引用关键 Bxxx / Jxxx / Rxxx 证据ID

## 关键发现

1. **风险传导路径复杂**：企业间的风险传导往往通过多层股权、担保、共同法人等关系进行，需要深入调查才能完整识别。

2. **担保链风险显著**：C002为C007提供600万元担保，C008为C007提供1,200万元担保，担保链风险是重要的风险传导路径。

3. **共同法人关联风险**：C001与C003共享法定代表人，C004与C008共享共同股东，这些关联关系可能产生间接风险传导。

4. **经营异常未处理**：C003、C007存在经营异常未处理的情况，信用风险信号较强。

5. **失信被执行人**：C002已被列为失信被执行人，存在520万元未履行债务，是最严重的风险点之一。
