### 四、多跳关联风险

#### 1. 间接股东风险链
- **新源新能源材料有限公司（C004）**
  - **关系：** 持有C005公司60%股权（R005），通过C005间接影响C006。
  - **基本信息：** 新材料制造业，注册资本8,000万元，存续
  - **共同股东关系（R010）：** C004与C008存在共同自然人股东周启东。
  - **风险：** C004自身无经营异常或司法事件，但通过C005的司法败诉及C008的担保风险，可能间接受到影响。

#### 2. 风险传导路径
- **路径1：** C006 → C005（股东）→ C004（间接股东）。C005的司法败诉可能影响其分红能力，进而影响C006的股东回报。
- **路径2：** C006 → C007（控股子公司）→ C008（担保方）。C007的严重司法风险可能触发C008的担保责任，最终传导至C006的投资损失。
- **路径3：** C006 → C008（参股子公司）→ C007（被担保方）。C008为C007提供担保，形成交叉风险敞口。

### 五、风险总结与风险等级评定

#### 1. 主要风险点
- **控股子公司C007风险极高：** 多项司法被执行案件、股权冻结、限制消费令、经营异常，可能导致投资损失及连带责任。
- **参股子公司C008担保风险：** 为高风险子公司C007提供1,200万元担保，或有负债风险高。
- **股东C005司法败诉：** 可能影响其对C006的支持能力。
- **集团内部关联风险传导：** 通过股权、担保、共同股东等关系，风险可能在集团内扩散。

#### 2. 风险等级评定
- **企业自身风险：** 低（无司法事件，仅正常股东变更）
- **直接关联风险：** 高（C007风险极高，C008有担保风险，C005有司法败诉）
- **多跳关联风险：** 中（间接股东C004目前无异常，但通过关联路径存在风险传导可能）
- **综合风险等级：** **高**

#### 3. 建议
- 密切监控子公司C007的司法进展及经营异常状态。
- 评估C008担保风险敞口及潜在代偿影响。
- 加强对股东C005的财务状况跟踪。
- 审视集团内部关联交易及风险隔离措施。
